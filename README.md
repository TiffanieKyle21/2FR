# 2FR Ceramic website

Website for 2FR Ceramic: paint protection film, graphene coating, nano ceramic tint, detailing and repaint for cars and motorcycles.

## Run locally

1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.

Run `npm run build` to create the production site in `dist/`.

## Where to edit

- `src/App.jsx`: all text, services, branches, links and the photo lists (at the top of the file)
- `src/styles.css`: colours, fonts and layout
- `public/img/`: photos
- `public/logo.png`, `public/favicon.png`: logo and tab icon
